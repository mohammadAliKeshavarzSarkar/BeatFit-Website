کاتالوگ معرفی اولیه بیت‌فیت
========================

مسیر:
  public/catalog/index.html

مشاهده:
  1. npm run dev
  2. باز کردن http://localhost:5173/catalog/

خروجی PDF:
  دکمه «چاپ / ذخیره PDF» → Save as PDF · حاشیه None · Background graphics روشن

محتوا (۵ صفحه خلاصه):
  1. جلد — تمرین را زنده ببین
  2. مسئله — یک تمرین، دو شدت
  3. محصول — LIVE / HISTORY / PROGRESS
  4. مخاطبان — ورزشکار، مربی، مدیر باشگاه
  5. جمع‌بندی + تماس

هدف: شناخت اولیه — نه کاتالوگ فنی کامل.
