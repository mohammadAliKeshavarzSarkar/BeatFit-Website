## Each page acceptance procedure

- Read current source `<title>`, meta description, H1, real full copy, visuals and internal links.
- Distinguish commercial solution, product use, informational definition, how-to and comparison intent; avoid assigning the same primary query to two pages.
- Review Persian search examples, label query-source hypotheses separately from first-party Google Search Console impressions.
- Write human BeatFit text: natural `پایش`/`مانیتورینگ` synonyms, brand variants `بیت‌فیت`/`بیت فیت`/`BeatFit`, no keyword-stuffing or `meta keywords` tag.
- Implement only the necessary targeted source changes in a reviewed PR, with English audit notes.
- Run actual Build, SEO outputs, mobile title/description/H1/canonical/OG and sibling-page non-regression; keep verified source separate from deployed-site claims.
- Measure indexing/traffic only after legitimate first-party GSC and live HTTP/TLS evidence.
