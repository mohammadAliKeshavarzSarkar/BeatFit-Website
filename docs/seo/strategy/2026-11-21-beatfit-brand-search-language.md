# BeatFit Persian Brand Search Language — Lexical and Entity Guidance

**Date:** 2026-11-21
**Primary entity:** BeatFit (this project: `https://beatfit.ir`)
**Scope:** Branded queries, visible copy conventions, title composition and disambiguation. Not a trademark or legal opinion.

## Recommended writing

- Default canonical Persian brand spelling: **`بیت‌فیت`** (ZWNJ).
- Natural search variants: `بیت فیت`, `بیتفیت`, `BeatFit`. These belong in keyword research and query interpretation; **do not force all into the same visible paragraph**.
- Positioning modifier for generic branded search: **`سیستم پایش زنده ضربان قلب و تمرین گروهی`**.
- Qualified role phrases: `بیت‌فیت برای باشگاه`, `پنل مربی بیت‌فیت`, `اپلیکیشن ورزشکار بیت‌فیت`, `دمو بیت‌فیت برای باشگاه`.
- Prefer product-specific brand usage in navigation and entity/organization structured data over artificial `meta keywords`. Keep only truthful official URL/identity fields.
- Link from `/` naturally to `/gym`, `/coach`, `/athlete`, `/resources` and `/demo` as available, with destination-appropriate descriptive anchors.

## Disambiguation requirement

Public web search returned unrelated worldwide offerings using the Romanized name BeatFit, including `beatfit.ch`, `beatfit.co.uk`, and `beatfit.jp`. This shows *name ambiguity in sampled search results*, not proven brand conflict for Iranian users or Google indexing. Distinguish this specific BeatFit via accurate Persian brand, canonical domain, live HR monitoring category, and legitimate product proof. Never assert ownership or affiliation with these other names.

## Search Console future tests

Before claiming brand rankings or trend, obtain actual property access and separate exact queries for the above four spelling patterns, branded + gym-intent modifiers and branded + demo variants. Use GSC query/page dimensions and canonical selection; **no values are estimated here**. Do not treat a `site:` search returning no pages as conclusive exclusion.

## Do not target

Generic music-timing workout apps, clinical arrhythmia monitors, gym membership billing, unverified sensor e-commerce, automatic personalized medical/exercise prescriptions or competitor brand traffic unrelated to BeatFit's user task.

## Copy rule

Avoid mechanically adding `بیت فیت` to every blog H1. Readers searching an informational question should see a clear answer; branding naturally belongs in context, breadcrumb, site identity and a helpful next step.
